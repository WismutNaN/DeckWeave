# DeckWeave

Локальная модульная платформа для устройств, приложений и автоматизаций. Плагины предоставляют ввод, действия с типизированными результатами, состояние, экраны, подсветку и будущие media streams. Ядро связывает их через общие contracts, не содержит протоколов конкретного оборудования и не зависит от открытого окна UI.

Первый практический результат — ежедневно пригодная конфигурация Mirabox N4 Pro на Windows. Расширяемость заранее проверяется на разных keyboard/gamepad/surface descriptors, цепочках заданий, geometry-based lighting и media boundaries.

## Статус

Проект находится на стадии спецификации: исполняемого кода ещё нет. Аудит и сравнение исходников 2026-10-12 уточнили архитектуру; runtime и hardware свойства предстоит подтвердить fixtures. Следующая работа — [Фаза 1](docs/implementation/roadmap.md#фаза-1--скелет-репозитория).

## Лицензирование

Подтверждённая стратегия: приложение и core — `GPL-3.0-or-later`; protocol, SDK и минимальные examples — `MIT OR Apache-2.0`. Лицензия каждого package указывается отдельно; каждый перенос кода требует provenance и проверки конкретных файлов/dependencies. Стратегия до появления кода не означает, что все будущие заимствования уже проверены.
