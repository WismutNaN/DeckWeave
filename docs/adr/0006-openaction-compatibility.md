# ADR-0006: OpenAction/Elgato как ранний compatibility bridge

**Дата:** 2026-10-11  
**Статус:** Принято

## Контекст

DeckWeave нуждается в полезных интеграциях раньше, чем сможет создать собственный каталог. OpenAction обратно совместим с существенной частью Stream Deck SDK, а OpenDeck подтверждает работоспособность отдельного plugin host.

## Рассматриваемые варианты

1. **Только собственный SDK** — чистая модель, но мёртвый старт без экосистемы.
2. **Сделать legacy API внутренней моделью** — высокая совместимость, но блокировка универсальных устройств.
3. **Compatibility host на границе** — перевод legacy contexts в capabilities и сохранение собственной модели.

## Решение

Выбрали **ранний OpenAction/Elgato compatibility host** с измеряемыми уровнями C0–C5. Базовая семантика определяется опубликованными протоколами и открытыми fixtures. GPL-compatible код может использоваться только как явно зафиксированное заимствование с provenance и review; legacy-specific data в любом случае не входит в core contracts.

## Последствия

**Становится проще:** использовать существующие actions и постепенно переписывать нужные plugins.  
**Становится сложнее:** нужен WebSocket host, PI isolation и compatibility matrix.  
**Закрывает дверь на:** обещание полной совместимости без теста конкретной версии package и перенос device-centric legacy domain в core.
